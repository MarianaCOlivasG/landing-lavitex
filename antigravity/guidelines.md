# Paleta de colores (usar exactamente estos valores)

- Primario — #10B2CC (Color principal de la marca / acentos principales)
- Secundario — #166D92 (Color de soporte / variantes de acento)
- Tercero — #F8FAFB (Fondo claro / superficies secundarias)
- Neutro — #4A5568 (Texto secundario / elementos neutrales)
- Blanco — #FFFFFF (Fondos limpios / base de UI)

- Fondo principal: Blanco / #F8FAFB
- Botones primarios: Primario (#10B2CC)
- Botones secundarios: Secundario (#166D92)
- Headers / navegación: Secundario (#166D92)
- Tarjetas destacadas: Tercero (#F8FAFB)
- Texto principal: Neutro (#4A5568)
