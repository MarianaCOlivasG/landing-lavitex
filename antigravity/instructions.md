# Objetivo del proyecto

Crear una aplicación web para **Lavitex del Caribe**, usando **NextJS (App Router)** y **Tailwind**.

El proyecto ya está creado y con Tailwind instalado, pero sin estilos ni funcionalidades. El objetivo es implementar el diseño y las funcionalidades básicas de una **landing page corporativa con panel administrativo**, moderna, premium y minimalista, siguiendo exactamente los diseños presentados en las referencias que serán proporcionadas, las cuales se encuentran en la carpeta de **"Antigravity"** dentro del proyecto.
